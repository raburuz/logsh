# Event

To send events to Bigstats, make a POST request to the following endpoint:

```plaintext
https://bigstats.com/api/event
```

### Request Body
```json
{
  "workspace": "bigstats",
  "event": "user_signup",
  "description": "User signed up for the newsletter.",
  "icon": "🚀"
}
```

| Name    | type | Description          | Restrictions |
| ------- | ---- | -------------------- | ------------ |
| workspace  | String    | Workspace name | Required |
| event  | String    | Event name | Required |
| description  | String    | Event description | Required |
| icon  | Emoji    | Event icon | Optional |

Validation Rules:

| Name | Validators | Example |
| ---- | ---------------- | ------- |
| workspace | Must be a non-empty string. <br /> Max length: 35 characters. | bigstats |
| event | Must be a non-empty string. <br /> Max length: 250 characters. | user_signup |
| description | Must be a non-empty string. <br /> Max length: 150 characters. | User signed up for the newsletter. |
| icon | Optional, if provided must be a non-empty string. <br /> Must be a valid emoji. | 🚀 |

Notes: 

- If the **workspace** you provide doesn't exist in your Bigstats workspaces we will create it for you automatically.
- The **workspace** aren't case-sensitive for practical purposes, so "Bigstats" and "bigstats" will be treated the same.

### Request Headers

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer YOUR_API_KEY"
}
```

| Name    | type | value          | Restrictions |
| ------- | ---- | -------------------- |   --------- |
| Content-Type  | string    | application/json | Required |
| Authorization  | string    | Bearer YOUR_API_KEY |Required |

### Response
A successful request will return a 200 OK status with a JSON response:

```json
{}
```

and a failure will return an appropriate error status code and message.

| Status  | Name | Message          |
| ------- | ---- | -------------------- | 
| 400  | bad_request | Invalid body parameters provided.| 
| 401  | unauthorized | Your Bearer Token is missing, invalid or expired. | 
| 402  | payment_required | You have reached the maximum number of monthly events.| 
| 429  | rate_limit_exceeded | Rate limit was exceeded. | 

### Example using JavaScript (Fetch API)

```js title="JavaScript Example"  caption="Send an event to Bigstats"
export const sendBigstatsEvent = async ( data ) => {
 
  const response = await fetch(
    'https://bigstats.com/api/event', 
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer bigstats_api_key_here', // Your API Key
      },
      body: JSON.stringify({
        workspace: data.workspace,    // Your workspace name
        event: data.event,            // Event name
        description: data.description, // Event description
        icon: data.icon,              // Event icons
      }),
    }
  )
 
  const result = await response.json();
 
  if( !response.ok ) {
    throw new Error(result.message || 'Failed to send event to Bigstats');
  } 
}
```
